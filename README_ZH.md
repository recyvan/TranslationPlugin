# 网页翻译助手（TranslationPlugin）

TranslationPlugin 是一款基于 Manifest V3 的浏览器扩展，可在网页原位置翻译内容。支持保留原文的双语对照，也支持只显示译文并随时恢复原文；翻译服务可选谷歌免费接口或自定义 OpenAI 兼容、Claude 兼容的 AI 接口。

[English](README.md) · 简体中文

## 功能

- 翻译网页中的可见文本，以及 `placeholder`、`title`、`alt`、`aria-label` 等常见属性。
- 支持开放 Shadow DOM、浏览器允许注入的网页框架，以及动态加载内容的重扫。
- 双语模式在原文旁插入译文；纯译文模式替换原文。操作后可恢复页面原始内容。
- 对文本去重并批量请求，支持本地翻译缓存、并发设置、失败块重试和页面进度徽章。
- 可配置多个 AI 服务方案、自定义系统提示词，以及通用、学术、计算机技术翻译风格。
- 支持 OpenAI 兼容 `/chat/completions` 与 Claude 兼容 `/v1/messages` 接口格式。
- 可为谷歌翻译和已配置的 AI 接口设置代理，也可使用全局自定义代理。

## 本地安装

1. 下载或克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions`，或进入其他 Chromium 浏览器的扩展管理页面。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择本仓库目录。
5. 使用 AI 服务前，先进入扩展设置完成 AI 方案配置。

扩展无需构建步骤，直接从源码目录加载。浏览器需要支持 Manifest V3；代理功能还需要支持 `chrome.proxy` API。

## 快速开始

1. 打开网页并点击扩展图标。
2. 选择目标语言和翻译服务。
3. 点击**翻译此页**。
4. 使用页面右下角的进度徽章查看状态、重试失败内容或恢复原文。

谷歌翻译无需 API Key，但可用性和限流情况受当前网络出口影响。使用 AI 翻译时，进入**设置 → AI 翻译**创建方案，填写接口地址、API Key 和模型名称，并将该方案设为当前使用。

## AI 接口配置

OpenAI 兼容接口可填写服务 Base URL（例如 `https://api.example.com`），也可直接填写完整的 `/chat/completions` 地址。Claude 兼容接口可填写服务 Base URL 或完整的 `/v1/messages` 地址；扩展会在需要时补齐接口路径。

批量翻译要求模型按行号返回结果，并校验每行是否有译文。若模型输出格式不匹配，扩展会拆分批次后重试。自定义系统提示词应允许保留批次编号格式，否则可能增加请求次数和等待时间。

## 代理设置

代理模式包括使用浏览器默认设置、强制直连、自定义代理，以及仅让翻译 API 或整个浏览器走自定义代理。仅 API 模式会将 `translate.googleapis.com` 和已配置的 AI 方案主机加入 PAC 规则，其他网页流量保持直连。若代理被其他扩展或企业策略接管，本扩展可能无法修改浏览器代理。

## 常见问题

- **有些文字没有翻译：** 开始翻译时，文字需要处于可见状态。点击或聚焦后显示的菜单会触发重扫；高度动态的页面可能还需要重新扫描。
- **页面很长：** 单次最多处理 1500 个正文文本单元；正文未达到上限时，还会处理最多 300 个可翻译属性条目。
- **页面看起来没有变化：** 查看页面徽章是否报告失败块并尝试重试。接口超时、限流、API Key 错误或代理规则不匹配都可能影响翻译。
- **AI 等待时间较长：** 可降低 AI 并发数、缩短自定义提示词，并检查 API 主机是否匹配代理规则。请求有超时控制，并会对暂时性错误重试。
- **IEEE Xplore 等组件较多的页面显示异常：** 建议先使用双语模式。复杂布局、框架重绘、定高裁剪容器和封闭 Shadow DOM 都可能限制译文插入位置。

## 隐私与数据处理

待翻译文本会发送到当前选择的翻译服务。API Key 和设置保存在浏览器本机的扩展存储中。项目没有配置遥测服务。请勿将网页内容发送给你不信任的翻译服务或代理。

## 项目结构

- `content/`：收集网页文本、回填译文、监听动态内容并恢复原文。
- `background/`：调用翻译服务、缓存结果、重试请求、记录用量并设置代理。
- `popup/`：当前网页的快捷操作。
- `options/`：语言、服务方案、代理和用量设置。

项目目前没有 npm 依赖或构建步骤。修改源码后，在扩展管理页面重新加载扩展即可。

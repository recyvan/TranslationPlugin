常规

AI 翻译

可保存多套 API 方案（如 DeepSeek、Claude 各一套），翻译时始终使用「当前使用」选中的方案， 不会在方案之间自动切换。支持 OpenAI 兼容（/chat/completions）与 Claude 兼容（/v1/messages）两种接口格式。

代理

用于访问在国内无法直连的翻译接口（如谷歌翻译）。 「仅翻译相关 API」通过 PAC 脚本只让翻译请求走代理，不影响其他网站； 「全局代理」会修改整个浏览器的代理设置。

用量统计

按实际使用的翻译服务分类统计（缓存命中不重复计费）。AI token 优先采用接口返回的真实用量，缺失时按字符估算。数据仅保存在本机。

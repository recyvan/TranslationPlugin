# 网页翻译助手（浏览器翻译插件）

一个 Chrome / Edge 浏览器扩展（Manifest V3），可以**一键翻译整个网页**，支持免费翻译接口与自定义 AI 大模型翻译，支持代理访问。

![图标](icons/icon128.png)

## 功能特性

### 整页翻译
- **段落级翻译**：同一段落内被行内标签切开的句子自动合并为整段送翻，上下文完整、译文质量更高，请求数与 token 消耗更低
- 一键翻译当前网页全部正文内容，右下角徽章实时显示进度
- 两种显示模式：**双语对照**（原文在上，整行译文在下，可自定义译文颜色）/ **仅显示译文**（替换原文）；flex 导航栏、按钮等紧凑容器内自动降级为行内译文，不破坏布局
- 随时**恢复原文**，随时再次翻译
- **全站覆盖**：
  - iframe 内嵌文档同步翻译（弹窗 / 右键 / 快捷键对所有框架生效）
  - Web Components / 开放 Shadow DOM 内容照常翻译
  - 表单 `placeholder`、图片 `alt`、`aria-label`（`title` 悬浮提示为双语）
  - 点击 / 聚焦后自动翻译新显示的下拉菜单、弹层
  - Vue / React 等框架把译文改回原文时自动恢复，改成新内容时自动重翻
- **动态内容自动翻译**：SPA 单页应用、无限滚动加载的新内容会自动跟进翻译
- 智能跳过：代码块、表单控件、`notranslate` 标记区域不被翻译；纯符号、数字不浪费请求
- 页面语言与目标语言相同时自动跳过，不浪费 API 配额
- 部分失败的文本可从徽章面板一键**重试**
- 翻译缓存：相同内容不重复请求（上限 6000 条）
- **站点自动翻译**：弹窗勾选「自动翻译此站点」后，打开该站页面即自动翻译

### 翻译服务

| 服务 | 说明 | 配置 |
| --- | --- | --- |
| 谷歌翻译（免费接口） | 无需任何密钥，开箱即用 | 无 |
| AI 翻译 | OpenAI 兼容或 Claude 兼容接口，翻译质量最佳 | 接口地址 + API Key + 模型名 |

> 微软必应翻译通道已于 2026 年下线（`edge.microsoft.com` 的免费鉴权端点全球返回 404），本插件自 v1.5.2 起不再提供该服务。国内网络如无法直连谷歌，请在设置页「代理」中配置代理，或改用 AI 翻译。

AI 翻译服务示例（接口格式在设置中选择）：

| 格式 | 服务 | Base URL | 模型示例 |
| --- | --- | --- | --- |
| OpenAI 兼容 | DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenAI 兼容 | 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI 兼容 | Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| OpenAI 兼容 | OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Claude 兼容 | Anthropic | `https://api.anthropic.com` | `claude-sonnet-4-5` |

**AI 多方案**：可保存多套 API 配置并随时手动切换（设置页管理，弹窗可快速切换当前方案）；翻译时始终使用选中的方案，**不会自动切换**。

**翻译风格（可选，所有方案共用）**：通用 / 学术（论文文献：规范术语译法、关键术语保留英文原文、书面句式）/ 计算机技术（业界通用译名，代码、命令、API 名称保留原文）。

### 代理
- **不使用代理**：跟随浏览器默认（默认）
- **强制直连**
- **自定义代理**：支持 HTTP / HTTPS / SOCKS5，两种生效范围：
  - **仅翻译相关 API 走代理**（推荐，PAC 脚本实现，自动包含 AI 接口域名，不影响其他网站）
  - **全局**（修改整个浏览器的代理设置）
- **与其他代理扩展的冲突**：浏览器同一时刻只允许一个扩展控制代理。若已安装 SwitchyOmega、Clash 类代理扩展并接管了代理，本插件会检测到（`levelOfControl`）并在设置页显示红色警告，不会盲目写入；此时请在对方扩展中为翻译 API 配置规则，或停用后再保存本插件的代理设置
- 设置保存、扩展安装、浏览器重启时自动应用

### 用量统计
- 设置 → 用量：今日 / 累计用量**按实际使用的服务分类**展示——谷歌翻译、AI·模型名各一行
- 每行含翻译字符数、API 请求数；AI 服务额外显示 token 数
- AI token 优先采用接口返回的真实 usage（prompt + completion），缺失时按字符数估算
- 缓存命中不重复计数；数据仅保存在本机，自动只保留最近 30 天，可一键清空

### 其他
- 14 种目标语言，源语言自动检测
- 弹窗内置**快速翻译框**（选中即用，Enter 翻译）
- 右键菜单「翻译整个网页 / 恢复原文」（可在设置中关闭）
- 快捷键 **Alt+T** 翻译 / 恢复当前页
- 智能使用逻辑：按钮随状态变化（翻译此页 → 停止翻译 → 恢复原文）；页面已翻译时修改语言 / 模式 / 服务自动重译；服务未配置时弹窗提醒
- 站点黑名单：不翻译指定站点（弹窗一键添加，勾选即恢复原文）
- 设置导入 / 导出、恢复默认、清除缓存
- 深色模式自适应

## 安装（开发者模式加载）

1. 下载本项目到本地
2. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目文件夹
5. 工具栏出现「译」字图标即安装成功

## 使用说明

1. 打开任意网页，点击工具栏图标
2. 选择目标语言、显示模式、翻译服务
3. 点击「翻译此页」（或按 Alt+T / 右键菜单）
4. 再次点击按钮或选择「恢复原文」还原页面

> 首次使用建议在设置页「测试连通性」确认所选服务可用。

## 常见问题

**谷歌翻译接口连不上？**
谷歌免费接口的域名（`translate.googleapis.com`）在国内无法直连，请在设置页「代理」中配置代理（如本地 Clash 默认 `127.0.0.1:7890`），推荐「仅翻译相关 API」模式；该域名已自动纳入代理范围。

**AI 翻译报 404？**
OpenAI 兼容格式：DeepSeek 填 `https://api.deepseek.com`，OpenAI 填 `https://api.openai.com/v1`（带 `/v1`）。Claude 兼容格式：填 `https://api.anthropic.com` 即可（插件自动补全 `/v1/messages`）。可用「获取模型列表」验证地址与密钥是否正确。

**翻译某网站没反应？**
该站点可能在黑名单中（弹窗底部可查看/取消），或是浏览器内部页面（`chrome://` 等）不支持扩展内容脚本。

**翻译会花钱吗？**
谷歌免费接口不产生费用；AI 翻译按你所用服务商的计费规则扣除 token，整页翻译通常消耗数千 token（设置页「用量」可查看统计）。

## 隐私说明

- 所有设置（含 API 密钥）仅保存在本机 `chrome.storage.local`，**不会同步到云端**
- 仅在点击翻译时，将需要翻译的文本发送到你选择的翻译服务（谷歌 / 你配置的 AI 服务）
- 不收集任何浏览记录、不注入任何跟踪代码

## 项目结构

```
├── manifest.json              # 扩展清单（MV3）
├── background/
│   ├── service-worker.js      # 后台：消息路由、缓存、并发、重试
│   ├── providers.js           # 翻译服务适配层（google / ai，含 Claude 格式）
│   ├── proxy.js               # 代理管理（chrome.proxy + PAC）
├── content/
│   ├── core.js                # 整页翻译核心（DOM 收集 / 写回 / 观察器，无 chrome 依赖）
│   ├── content.js             # 内容脚本桥接 + 页面进度徽章（Shadow DOM）
│   └── content.css            # 双语译文样式
├── popup/                     # 弹窗
├── options/                   # 设置页
├── shared/                    # 共享常量（语言表、默认设置）
├── test/                      # 测试页（mock chrome API 端到端验证核心逻辑）
├── tools/
│   ├── check.js               # 校验脚本：语法 / manifest / MD5 / PAC / 注册表
│   └── gen_icons.ps1          # 图标生成脚本
└── CHANGELOG.md               # 迭代记录
```

## 开发

```bash
# 运行全部校验（语法、manifest 引用、MD5 正确性、PAC 语法、服务注册）
node tools/check.js

# 浏览器打开 test/harness.html 可自动运行核心逻辑的 20+ 项断言
```

技术要点：后台 Service Worker 统一代理所有翻译请求（规避页面 CORS 限制）；批量文本按 `\n` 合并请求后按行对齐，对不齐自动降级逐条；AI 使用编号行协议；失败指数退避重试。
